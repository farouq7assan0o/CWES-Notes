# CWES-Notes

## About This Repository

Hey 👋

This repository contains my **personal notes from the Hack The Box Web Penetration Tester Job Role Path**, which prepares for the **HTB Certified Web Exploitation Specialist (CWES)** certification.

I created these notes while studying and practicing the modules because I realized that writing everything down in a **structured, repeatable way** helps a lot with learning and retention.

Instead of keeping the notes private, I decided to publish them here so that **other learners going through the same path can benefit from them as well.**

These notes cover the modules from the HTB path and include:

- Concepts
    
- Methodologies
    
- Commands
    
- Payloads
    
- Attack workflows
    
- Practical examples
    
- Key takeaways
    

My goal was to create something that is **practical for both studying and real-world use during testing**.

# Structure of the Notes

The repository is organized roughly in the same order as the **HTB Web Penetration Tester path**.

Some of the modules included:

- Web Requests
    
- Introduction to Web Applications
    
- Using Web Proxies
    
- Information Gathering
    
- Web Fuzzing
    
- JavaScript Deobfuscation
    
- Cross-Site Scripting (XSS)
    
- SQL Injection
    
- SQLMap Essentials
    
- Command Injection
    
- File Upload Attacks
    
- Server-Side Attacks
    
- Authentication Attacks
    
- File Inclusion
    
- API Attacks
    
- GraphQL Attacks
    
- Bug Bounty Methodology
    

Each topic typically contains two types of notes:

### Commands Notes

Quick-reference commands, payloads, and testing patterns.

Useful when you need to **execute attacks or replicate labs quickly**.

### Explanation Notes

Concept explanations and methodology breakdowns.

Useful when you want to **understand why something works**, not just how.
